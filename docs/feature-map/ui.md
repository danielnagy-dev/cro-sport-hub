# UI

Entries for the UI library. Shared preconditions and driving conventions are in `docs/feature-map.md`.

Each ui feature id has its own file under `docs/feature-map/ui/`. The file name is `<id>.md` (for example `ui.library.md`). A new ui feature adds that id file only. This area file does not hold an index table or per-id sections.

Planned entry points are estimates. The change that builds each feature updates its id file.
