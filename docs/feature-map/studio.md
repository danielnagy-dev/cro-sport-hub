# Studio

Entries for the studio. Shared preconditions and driving conventions are in `docs/feature-map.md`.

Each studio feature id has its own file under `docs/feature-map/studio/`. The file name is `<id>.md` (for example `studio.login.md`). A new studio screen adds that id file only. This area file does not hold an index table or per-id sections.

Planned entry points are estimates. The change that builds each feature updates its id file.
