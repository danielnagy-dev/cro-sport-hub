# Web

Entries for the web app. Shared preconditions and driving conventions are in `docs/feature-map.md`.

Each web feature id has its own file under `docs/feature-map/web/`. The file name is `<id>.md` (for example `web.home.md`). A new web feature adds that id file only. This area file does not hold an index table or per-id sections.

Planned entry points are estimates. The change that builds each feature updates its id file.
