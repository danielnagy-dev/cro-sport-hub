# API

Entries for the API. Shared preconditions and driving conventions are in `docs/feature-map.md`.

Each API feature id has its own file under `docs/feature-map/api/`. The file name is `<id>.md` (for example `api.health.md`). A new API feature adds that id file only. This area file does not hold an index table or per-id sections.

Planned entry points are estimates. The change that builds each feature updates its id file.
